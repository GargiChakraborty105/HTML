Semantic HTML

Semantic HTML uses elements that describe the meaning of their content.

About Elements

Why use semantic elements?

Meaningful markup makes pages easier to understand, maintain, and navigate with assistive technology.

Common semantic elements

Page structure

  • <header> introduces a page or section.
  • <nav> contains navigation links.
  • <main> contains the page's primary content.
  • <section> groups content around a topic.
  • <article> represents self-contained content.
  • <aside> contains related supplementary content.
  • <footer> contains footer information.

Choose elements for their meaning; use CSS to control their appearance.
